# field-fox.com

Source repository for the Field-Fox personal website at [field-fox.com](https://field-fox.com).

The current static site is in [`field-fox-landing/`](field-fox-landing/). It can be deployed with Cloudflare Pages without a build step.

## Cloudflare Pages settings

- Production branch: `main`
- Build command: leave blank
- Build output directory: `field-fox-landing`
